# Dashboard de Metas

Meu primeiro projeto em Streamlit. Um gerenciador de metas com categorias, status de conclusão e reset de dados.

Foi onde aprendi a trabalhar com `session_state` para manter o estado entre as interações da interface.

---

## Stack

`Python` `Streamlit`

---

## Como rodar

```bash
git clone https://github.com/viniciusroland01/dashboard_pratica.git
cd dashboard_pratica

pip install streamlit

streamlit run script.py
```
